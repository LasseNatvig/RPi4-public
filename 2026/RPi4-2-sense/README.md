# README.md

## TDT4258 - 2026 - RPi4-2-sense

This folder contains a simple C file used in course TDT4258 - 2026 - for demonstrating i2c programming for two of the many sensors on the Raspberry Pi sense hat.

It has a page in the TDT4258 course canvas that give links to datasheets and to a canvas discussion. The canvas page also describes the purpose of the example and how it was developed.

Comments to the example can be e-mailed to course lecturer Lasse Natvig.

## Compiling and running

Assuming vsCode, compile by "make" in terminal, an run by ./sensehat in terminal. Debug by pressing F5 when cursor is in the C-file.

vsCode setup, makefile etc. is the same as used in the previous example RPi4-1-setup

It was last tested at 2026-08-28.
